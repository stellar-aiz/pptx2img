# 表スタイル

presentation の tableStyles 関係と tableStyleId から埋め込みスタイルを解決する。
wholeTbl、行列の帯、最初・最後の行列、隅セルの順に書式を合成し、
最後にセルの明示書式を優先する。塗り・罫線・文字色・太字・斜体・fontRefを扱う。
文字配置は既存の処理へ渡し、結合セルの範囲判定と継続セルの省略を維持する。

未解決ID（組み込みスタイルがパッケージに含まれない場合も含む）、
表スタイル内のfillRef/線参照、未対応の表全体書式は診断を残す。
スタイルの種類を全面対応したという意味ではない。

仕様はECMA-376 Part 1 DrawingMLの表スタイルを参照し、独立実装した。
ibis-office のコード・テスト・素材は転用していない。

自作資料は `python tests/visual/make_table_styles.py /tmp/tables.pptx` で生成。
スタイル指定と同等の明示指定のPNGはバイト単位で一致した。
見出しの結合セル、交互の帯、末尾セルの明示色、罫線・文字を含む。
LibreOffice 26.2.5.2との比較は2ページともMAE 0.012951・差分率3.133%で
既存閾値内。主な残差は文字位置であり、閾値は緩めていない。
