# 要求仕様

この文書は呼び出し側の要求を保持する。実装済みの範囲を表す文書ではない。
完成判定には全項目の実装証拠と検証証拠が必要。

## 目的と統合

- 印刷設定済みの見積書・帳票を Excel 本体と同じ紙面の PDF にする。
- 再現できない要素が一つでもあれば近似せず停止する。
- 呼び出し側のツールから CLI を一度呼ぶ。印刷設定検査と PDF 成果物検証は
  呼び出し側に残す。
- macOS Seatbelt、Windows AppContainer、Linux bwrap 内で実行する。
- 実行時は Office、LibreOffice、ブラウザ、Python、Node に依存しない。

## 入出力と診断

- 入力は `.xlsx` 一つ。`.xls`、`.xlsm`、暗号化入力は理由付きで拒否。
- 出力は PDF 一つ。既存ファイルを上書きせず、失敗時に途中の PDF を残さない。
- 成功は stdout、失敗は stderr に YAML 一件（rhodopsin CLI の結果文書形式）。
  成功時にはページ数、各ページの寸法、対応シートの順番と範囲、
  使用フォントと埋め込み状態、警告を含む。
- 失敗時は分類・理由・位置（1 始まりのシート順番、セル番地）を返す。
  特定セルに限定できない場合、セル番地は null。
- 診断にセル値・文字列・シート名を含めない。位置・件数・種類のみとする。
- 終了コードは rhodopsin CLI に合わせ、0 成功、1 変換失敗、2 引数不正。
  失敗の分類（入力不正・対応外要素・フォント不足・ページ組み立て失敗・
  内部エラー）は結果文書の `code` で返す。

## 実行環境と資源

- 単一バイナリ。macOS arm64 / x86_64、Windows x86_64、Linux x86_64。
- ネットワークアクセスと子プロセス起動を行わない。
- 読むのは入力と明示したフォント探索先だけ。書くのは出力先だけ。
- 一時ファイルが必要なら出力先と同じディレクトリに作成し、終了時に除去。
- メモリ、ZIP 展開量、シート・セル数、画像展開量を制限する。
- 同じ入力と同じフォントで同じ PDF。日時・ID を固定する。

## 値と表示形式

- 数式は再計算せず保存済み結果を使う。結果がなければ停止。
- 標準、桁区切り、小数、通貨、会計、パーセントを Excel に合わせる。
- 正・負・ゼロ・文字列の区分、色指定、日付・時刻、和暦、DBNum1–3、
  組み込み numFmtId に対応する。
- 数値の列幅不足は Excel と同じ `###` 表示とし、位置・件数を警告する。
- 文字列は隣接セルの空き具合に応じて Excel と同じ規則ではみ出し・切断。

## 紙面

- セル値、フォント書体・サイズ・太字・斜体・下線・色。
- 単色の塗り、罫線の線種・太さ・色、横縦配置・折り返し・字下げ、結合。
- 保存済み列幅・行高。列幅の換算には実フォントの数字幅を使う。
- 印刷範囲、用紙、縦横、倍率、横 n × 縦 m ページへの収容、余白、
  水平垂直中央寄せ、手動改ページ、繰り返し行・列。
- 非表示行・列・シートは印刷しない。
- セルに固定された PNG / JPEG 画像、テーマ色・テーマフォント。

## 初版で拒否する要素

図形、テキストボックス、グラフ、条件付き書式、テーブルスタイル、
グラデーション、縦書き、回転文字、縮小表示、ヘッダー・フッター、
コメント印刷、シート間で異なる印刷方向。種類と位置を報告する。
範囲拡張は要素ごとに実装し、近似で処理を継続しない。

## フォントと PDF

- Microsoft / Apple フォントを同梱しない。
- OS フォント置き場と `--font-file` 指定ファイルから探す。
  探索先と sandbox の読み取り許可を整合させる。
- 書体がなければ既定で停止。明示オプションによる代用だけを許可し警告。
- 描けない文字が一つでもあれば停止。
- 文字をパスにせず、使用グリフのサブセットを埋め込み、ToUnicode を付ける。
  呼び出し側が全セルの文字列を PDF から照合できること。

## 正しさと比較

- 正解は Excel 本体の「PDF として保存」。LibreOffice は比較観測用。
- 同じ非機密 `.xlsx` から生成した Excel PDF、rhodopsin-xlsx PDF、
  LibreOffice PDF の三者を比較する。入力と参照 PDF を保存し、
  アプリのバージョン、OS、フォント、生成手順を記録する。
- ページ数・寸法、改ページ位置（先頭末尾のセル）、全文字列、文字位置、
  ラスタライズした画像差を比較する。
- 位置の許容誤差は根拠付きで定め、差を隠すために緩和しない。
- 既知の差には再現 fixture を付ける。LibreOffice との一致だけでは合格しない。
- 開発時の外部比較ツールは、配布バイナリの実行時依存に含めない。
- 三者比較の判定と記録方法は [検証方針](validation.md) に従う。
