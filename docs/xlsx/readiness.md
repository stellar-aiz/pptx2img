# 完成条件との照合

2026-10-20 時点。要求は [requirements.md](requirements.md) に保持し、
実装済みの範囲へ縮小しない。下表は現ソースとテストの照合結果であり、
製品の合格表ではない。合成フォントは空のアウトラインを持つため、
そのテストが通っても実フォントの紙面一致を証明しない。
元リポジトリにあった日付付きの進捗記録は、rhodopsin への統合時に取り込んでいない。

## 処理と合成テストがある項目

以下も全体完成とは区別する。各モジュールの局所的な検証証拠である。

| 要求 | ソース・検証箇所 | 証拠の限界 |
| --- | --- | --- |
| 入力形式・暗号化・数式キャッシュの検査 | `package.rs`、`workbook.rs`、`tests/input.rs` | 読み取れる実帳票すべてを調べた証拠ではない |
| 診断の秘匿・分類・終了コード | `diagnostic.rs`、`main.rs`、CLI 入力テスト | 成功経路は未接続 |
| 非上書き・一時ファイルの後始末 | `output.rs`、`tests/output.rs`、内部競合テスト | 強制終了・電源断時の一時ファイル残存を防ぐ保証ではない |
| 資源制限 | package・font・layout・scene・PDF 各 Limits と境界テスト | プロセス全体の厳密なピークメモリ保証ではない |
| 印刷範囲・余白・倍率・収容・改ページ・繰り返し・非表示 | `print.rs`、`layout.rs`、`workbook_layout.rs` と対応テスト | 未対応の部分改ページ等があり、Excel の改ページ位置は未照合 |
| 実フォントの数字幅による列幅計算 | `fonts.rs`、`layout.rs`、`tests/workbook_layout.rs` | Excel との測定・印刷結果の一致は未照合 |
| 固定数値・会計・区分・色・日付・和暦 | `format/` と format・date テスト | 組み込み番号・地域依存規則の全体対応ではない |
| 値・書体・単色塗り・テーマ・画像 | cell_text・cell_paint・theme・drawing・image_geometry と対応テスト | 配置済み API の合成検証が中心 |
| 初版の対応外要素を拒否 | workbook・styles・drawing・print の入力検査 | 全要素の完全な検出網を証明するものではない |
| 書体探索・明示代用・欠落検出・埋め込み | font_sources・system_fonts・fonts・PDF と対応テスト | OS 実行差、探索中のパス差し替え、未対応のフォント形式等が残る |
| 同一入力からの PDF 決定性 | PDF・ブック組版の再生成テスト、固定 ID | 実帳票・全対象 OS での決定性は未確認 |
| 外部実行系へ依存しない | 配布用 `src/` にプロセス起動・ネットワーク API は見当たらない | ソース検索だけで sandbox 内動作を保証しない |
| 寛容ライセンス・SBOM・NOTICE | 依存資料生成ツールの許可リスト検査と生成物 | 配布物の梱包・配布先での検証は未実施 |
