# 標準数値書式の観測ブック

General の表示選択を Excel 本体で確かめるための非機密な合成ブックを生成する。
生成したブックは Excel が作成した正解 fixture ではなく、観測の入力候補である。

```sh
cargo run --example make-general-probe -- target/general-probe.xlsx Arial
```

第一引数は未使用の `.xlsx` 出力先、第二引数は Excel 側で使用する実際の書体名。
指定書体の存在は生成時には確認しない。Excel 上で代用がないことを別途確認する。
既存ファイルを上書きせず、書体名を XML 属性へ安全に符号化する。
同じ書体名から同じブックのバイト列を生成する。

A 列は保存値の文字列、B–E 列は同じ保存値を General の数値セルとして保持する。
幅は A 列が 24、B–E 列が 3・8・16・28。行高 22 pt、書体サイズ 11 pt、
A4 縦・100%・四辺 0.5 inch の余白、印刷範囲 A1:E18 とする。
幅は保存された列幅単位であり、固定のポイント幅とはみなさない。
自動収容・数式・画像・罫線・ヘッダー等は付けない。

18 入力について四つの幅、計 72 数値セルを観測できる。

| 行 | 保存値 | 調べる境界 |
| --- | --- | --- |
| 1–3 | 0、1、-1 | ゼロ・符号・極端な幅不足 |
| 4–6 | 1234567890、12345678901、123456789012 | 10・11・12 桁 |
| 7–8 | 99999999999、99999999999.5 | 丸めと桁上がり |
| 9–13 | 0.1、0.0001、0.00001、0.000001、0.00000001 | 負の指数と先頭ゼロ |
| 14 | 0.000123456789 | 固定小数点と指数で保持できる精度 |
| 15 | 1.23456789012345 | 小数の表示精度 |
| 16 | -12345678901 | 負号の追加による幅の変化 |
| 17–18 | 1E20、1E-20 | 大きい正負の指数 |

[Microsoft の numFmt 説明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.numberingformat?view=openxml-2.8.1)
は、General の固定小数点表示の長さ、幅不足時の指数表示、表示不能時のハッシュ表示を
説明している。ただし、これだけで Excel の全ての幅・丸めの選択順を確定しない。
各セルの実表示、PDF 抽出文字、文字位置、印刷結果を保存して検証する。
観測前の期待値をコードで推測して正解データにしない。

Excel で入力を一度保存して正規化する場合は、保存後の `.xlsx` を正規の観測入力とし、
それから PDF を保存する。LibreOffice と rhodopsin-xlsx にも同じ保存後入力を渡す。
入力ハッシュ、アプリ・OS・書体の版、ロケール、再計算の有無、PDF 保存手順を
[検証方針](validation.md) に従って記録する。

入力検査による読み戻し、18 行の保存値・列幅・印刷範囲・書体名・生成の決定性を
テストした。Excel でのオープン・保存・PDF 出力は未実施。
